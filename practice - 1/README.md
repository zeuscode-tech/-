su переключает пользователя и обычно запрашивает пароль
целевого пользователя. su - загружает его окружение входа.
sudo выполняет разрешённую команду от имени другого пользователя,
по умолчанию root, обычно запрашивая пароль вызывающего пользователя.

В Ubuntu пароль root по умолчанию заблокирован, поэтому прямой
вход по паролю недоступен. Администрирование выполняют через sudo,
что позволяет ограничивать доступ и журналировать действия.
Учётная запись root при этом существует.
